# ia/ — rastro de cómo se dirigió la IA

Contenido de esta carpeta:

- `bitacora.md` — decisiones tomadas en la sesión de dirección (qué pedí, qué propuso la IA, qué decidí yo y por qué).
- `prompts/` — plantillas que usa la fábrica para pedirle código y pruebas a la IA (copia de lectura de `factory/prompts/`).
- `reglas/` — archivos de instrucciones del agente (CLAUDE.md y reglas de la fábrica).
- `transcripciones/` — transcripciones de las sesiones de construcción y de cada corrida del pipeline.

Herramientas: Claude (sesión de dirección/arquitectura) y Claude Code CLI en modo headless (`claude -p`) como motor de generación de la fábrica.
